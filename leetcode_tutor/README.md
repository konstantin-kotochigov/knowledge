# LeetCode Репетитор

Приложение-репетитор для ежедневной практики решения задач с LeetCode.

## Возможности

1. **Парсер задач LeetCode** - загружает задачи из открытой части LeetCode и сохраняет в базу данных (лимит 10-20 запросов в день)
2. **Генератор решений** - фоновый процесс, который с помощью LLM генерирует решения и подсказки для задач (лимит 10 запросов в день)
3. **Веб-приложение** - показывает 2 задачи на день с:
   - Формулировкой задачи (открыто)
   - Подсказкой (свёрнуто)
   - Решением (свёрнуто)

## Установка

### 1. Установите зависимости

```bash
cd leetcode_tutor
pip install -r requirements.txt
```

### 2. Настройте окружение

Скопируйте файл `.env.example` в `.env` и заполните необходимые данные:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```
OPENAI_API_KEY=your_openai_api_key_here
DATABASE_URL=sqlite:///leetcode.db
LEETCODE_PARSE_LIMIT=20
LLM_GENERATION_LIMIT=10
FLASK_SECRET_KEY=your_secret_key_here
FLASK_PORT=5000
```

## Использование

### Шаг 1: Инициализация базы данных и парсинг задач

Запустите парсер для загрузки задач из LeetCode:

```bash
python leetcode_parser.py
```

Парсер:
- Загружает задачи из LeetCode API
- Сохраняет их в базу данных
- Ограничивает количество запросов (по умолчанию 20 в день)
- Можно запускать несколько раз, пока не наберётся достаточно задач

### Шаг 2: Генерация решений и подсказок

Запустите генератор решений:

```bash
python solution_generator.py
```

Генератор:
- Находит задачи без решений или подсказок
- Использует OpenAI API для генерации решений на Python
- Создаёт полезные подсказки на русском языке
- Ограничивает количество запросов (по умолчанию 10 в день)
- Можно запускать периодически для обработки новых задач

### Шаг 3: Запуск веб-приложения

Запустите Flask приложение:

```bash
python app.py
```

Откройте в браузере: `http://localhost:5000`

Веб-приложение:
- Показывает 2 случайные задачи на день
- Задачи обновляются раз в сутки
- Формулировка задачи показана всегда
- Подсказка и решение скрыты за кликабельными заголовками

## Автоматизация

Для автоматической работы можно настроить cron задачи:

```bash
# Парсинг новых задач каждый день в 2:00
0 2 * * * cd /path/to/leetcode_tutor && python leetcode_parser.py

# Генерация решений каждый день в 3:00
0 3 * * * cd /path/to/leetcode_tutor && python solution_generator.py
```

## База данных

Приложение использует SQLite базу данных с тремя таблицами:

- **problems** - задачи LeetCode с описаниями, подсказками и решениями
- **daily_problems** - задачи, выбранные для показа в конкретный день
- **rate_limits** - счётчики для контроля лимитов запросов

## Ограничения

- Парсер: 10-20 запросов к LeetCode API в день
- Генератор: 10 запросов к OpenAI API в день
- Эти ограничения помогают контролировать расходы на API

## Требования

- Python 3.7+
- OpenAI API ключ
- Интернет соединение для загрузки задач и генерации решений
