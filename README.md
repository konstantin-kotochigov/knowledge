# Knowledge Repository

Here I store my condensed knowledge about Data Science / Analytics topics. Mostly they include Machine Learning, Computer Science and Mathematics with focus on theory (sometimes enriched with usage examples and exercises).

I try to make the descriptions as concise and clear as possible and offer them as an alternative to wordy textbooks - I restrain to the essential concepts only and bypass the ones that are too theoretic or inapplicable in practice.

I personally use it:
1. As a cheatsheet when I need to recall theory before the interviews
2. As a base for lessons when I need to teach some concept to students

## 🎯 LeetCode Tutor Application

A new **LeetCode Tutor** application has been added for daily coding practice!

### Features

- 📚 Automatic problem parsing from LeetCode (rate-limited to 10-20 requests/day)
- 🤖 AI-generated hints and solutions in Russian using OpenAI (rate-limited to 10 requests/day)
- 💻 Beautiful web interface displaying 2 daily problems
- 🎨 Collapsible sections for hints and solutions
- 🗄️ SQLite database for problem storage
